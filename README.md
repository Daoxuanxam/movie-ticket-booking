# 🎬 Movie Ticket Booking Website

A web application for booking movie tickets online, built with Java Spring Boot and MySQL.

## 📋 Features
- Browse movies and showtimes
- Select seats and book tickets
- User authentication (login/register)
- Payment processing with discount codes
- Admin dashboard: manage movies, bookings, users, revenue reports

## 🛠️ Tech Stack
- **Backend:** Java Spring Boot, Spring Security, Spring Data JPA
- **Frontend:** Thymeleaf, HTML/CSS, Bootstrap
- **Database:** MySQL
- **Architecture:** MVC Pattern

## 🚀 Setup
1. Import `cinema.sql` into MySQL
2. Update `application.properties` with your DB credentials
3. Run the Spring Boot application
